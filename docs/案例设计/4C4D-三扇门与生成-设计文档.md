## 4-3 三扇门（l4c）
句子任务："记住句首的【密码 7】，句尾报告它"。时间轴 8 步，LSTM 单元显示：
- 细胞状态 C 条（信息高速公路，加法更新：Cₜ = f·Cₜ₋₁ + i·c̃）；
- 三扇门滑杆：遗忘门 f、输入门 i、输出门 o（0~1 连续，makeKnob 或 lever）。

**幕一 预测**：要让密码活到句尾，遗忘门在中间各步应该开多大？
✓ 接近 1（保住 C）｜✗ 接近 0（清掉就忘了）〔M-SQ-03〕｜无所谓。
**幕二 实操**：句首"写入密码"（输入门开、写 c̃=7）；中间 6 步干扰词（每步学生拖 f：f<0.9 累积衰减可见）；句尾"读出"（输出门开 → h 输出 C）。
- 任务 A：让句尾输出 7（C 条存活 ≥6.5/7）；任务 B：句尾输出 0（中途用 f≈0 清空 C）——两个方向都做，体会"选择性记忆"。
- 实时显示 Cₜ 数值条与 0.5ⁿ 对照刻度（连回 4-2 的直觉：f=0.5 就是 RNN！）。
**幕三 概念两问**：
1. "细胞状态 C 和隐状态 h 的关系？" ✓ C 是长期记忆库，h 是经输出门读出的显状态；
2. "为什么说 C 是梯度高速公路？" ✓ 加法更新让反向梯度近似直通（×f≈1 而非连乘 tanh 导数）〔错：因为参数多→M-SQ-03〕。
完成证据：A/B 两任务达标 + 预测与概念题首答。

## 4-4 一句一句生成（l4d）
字符级 mini Seq2Seq："hell" → "olleh"（反转任务，5 词表）。可视：编码器 4 格把句压缩成一个向量条 → 解码器逐格吐字。
**幕一 预测**：Teacher Forcing 训练时，解码器第 3 步的输入是什么？
✓ 真答案的前一字（'l'）〔✗ 模型自己上一步的输出→M-SQ-04；随机字〕
**幕二 生成对比（交互主体）**：训练曲线两条（TF 开：loss 快速降；TF 关：降得慢但更稳）。按钮"生成一次"：
- TF 模式生成的示例：训练时每步都对 → 生成时第一步错就连锁错（展示一次"暴露偏差"翻车：输出 olleh→ollleh）；
- 学生点"重新生成"看自回归逐步展开（每步亮当前字与采样分布条）。
**幕三 困惑度两问**：
1. "模型 A PPL=12，B PPL=90？" ✓ A 更好（每词平均分支数更接近真实）〔B 准确率高→M-SQ-05〕
2. "训练用 TF、生成没有 TF，这个落差叫什么？" ✓ 暴露偏差〔过拟合→M-SQ-04〕
完成证据：预测+两问首答 + 完成一次自回归生成。
数据：字符级 toy 用确定性规则生成（编码向量=字符 one-hot 和），训练曲线用预设两条真实形状曲线（由 loss 公式形状生成，标注"教学构造"）。
