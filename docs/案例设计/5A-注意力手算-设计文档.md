## 1. 学习目标

1. 能算 score = q·k/√d（给 2 维小矩阵）；
2. 能对 score 做 softmax 得注意力权重（和为 1）；
3. 能算输出 = Σ wᵢ·vᵢ（加权求和）；
4. 能解释 √d 的作用（分数随维度变大、softmax 会饱和 → 除 √d 缓和）。

## 2. 结构：三步手算（每步先答后验，数值全程系统代劳乘加，学生只判断"怎么算、算出来大概是多少"）

2 词迷你例（数字可整除、便于聚焦规则）：
- q = [2, 0]；k₁=[1, 0], k₂=[0, 2]；v₁=[1, 2], v₂=[3, 4]；d=4 → √d=2
- **第 1 步 score**：s₁ = q·k₁/√d = 2/2 = 1；s₂ = q·k₂/√d = 0/2 = 0
  预测（双拨轮）：s₁、s₂。干扰项内置在自由输入后的归因（如 2〔忘除√d M-AT-03〕）
- **第 2 步 softmax**：w₁ = e¹/(e¹+e⁰) ≈ 0.731；w₂ ≈ 0.269
  预测（双拨轮，保留两位小数）。归因：0.5/0.5〔当成平均 M-AT-01〕、忘归一化〔分母只有自己 M-AT-04〕
- **第 3 步 输出**：out = w₁·v₁ + w₂·v₂ ≈ [1.462, 2.462]
  预测（双拨轮）。归因：直接用 score 加权〔M-AT-05〕
- **第 4 步 概念问**：为什么除 √d？三选一（分数随维度增大→softmax 饱和成 one-hot，梯度消失 ✓／为了归一化到 0-1／为了让矩阵可逆）
