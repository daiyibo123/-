# 案例 3-A《尺寸车间》设计文档 v1.0

章节：第3章 卷积神经网络 ｜ 对应大纲考核点："计算 CNN 输出尺寸和参数量" ｜ 课件依据：S36(深度)、S46/S51(空间维度)、S56(7×7 原题)
状态：待实现 → 待评审

## 1. 学习目标（可检验行为）

1. 给定 输入尺寸 W、核 F、步长 S、填充 P，能计算单层卷积/池化输出尺寸 O = ⌊(W−F+2P)/S⌋+1（含 floor 陷阱）；
2. 给定 C_in、核数 K、核大小 F，能计算卷积层参数量 = K×(F·F·C_in+1)；
3. 能计算两层堆叠（卷积+池化）后的最终输出尺寸；
4. 能解释公式每一项的含义（F 吃掉边长、P 双边各加、+1 是窗口起点数、floor 是跳步余数）。

## 2. 与"口算题"的本质区别（回应教师批评）

学生不做多位数乘加（那是计算器的事）：**练的是公式应用与自我纠错**。每题流程 = 先答（拨轮输入）→ 提交 → **可视化验证**（滑窗动画逐格数出窗口数 / 参数卡片逐项分解）→ 答错时高亮"你漏了哪一项"并归因到误区类别。数字全部选小（≤32），认知负载在公式而非算术。

## 3. 关卡结构（两幕）

### 第一幕 · 看懂公式（可跳过）
7×7 网格 + 三个拨轮（F∈{1,3,5,7}、S∈{1,2,3}、P∈{0,1,2}）：
- 实时：核窗口以高亮框显示，网格外圈显示虚线填充环（P>0）；
- 点"滑一遍"：窗口沿行滑动，每个落点标号 1,2,3…，落点数即输出宽；
- 公式实时装配：O = ⌊(W − F + 2P)/S⌋ + 1，数字随拨轮代入（F 变大→看到窗口变少；S=2→看到跳格；P=1→看到虚线环补回边长）。

### 第二幕 · 出题闯关（连对 5 题通关）
出题器按难度梯度出题（种子随机，数值每次变化）：

| 序 | 题型 | 示例（课程相关） | 考察 |
|---|---|---|---|
| Q1 | same 填充经典 | 输入7×7，核3×3，S=1，P=1 → 输出?（课件 S56 原题） | 公式完整应用 |
| Q2 | 无填充 | 输入28×28，核5×5，S=1，P=0 → 输出?（LeNet C1 输入风格） | 2P=0 情形 |

## 4. 错误归因（本应用核心价值）

按错误值精确匹配误区（每个误区预计算干扰值）：

| id | 误区 | 干扰值示例（Q4：K=6,F=5,C=1 → 正确156） |
|---|---|---|
| M-SZ-01 | 公式漏 +1（忘窗口起点） | Q1 答 6 |
| M-SZ-02 | padding 只加一边（2P→P） | Q1 答 6（同值不同因，按题区分） |
| M-SZ-03 | floor 错（四舍五入/向上取整） | Q3 答 4 |
| M-PR-01 | 忘偏置（+1） | 150 |
| M-PR-02 | 忘乘输入通道 C_in | Q4 变体 C=3 时答 144 |
| M-PR-03 | 忘乘核数 K | 26 |
| M-PR-04 | 混用输出尺寸 | — |

匹配到 → 讲解文案直指该误区（如"+1 是窗口起点数——你数滑窗动画的第一个落点"）+ 宠物走到公式处提示；未匹配 → 通用讲解（公式逐项高亮）。

## 5. 可视化验证设计

- **尺寸题**：1D 宽度条（W 格 + P 虚线环）动画滑窗，落点依次点亮标号，末尾落点数 = O；公式代入式逐项着色：⌊(7−**3**+**2×1**)/**1**⌋+1 = **7**。
- **参数量题**：参数卡片分解链：K=6 个核 × [F·F·C=25 权重 + 1 偏置] = 6 × 26 = 156，漏项标红并给差值（"漏偏置：每个核都有 1 个 b，共差 6"）。
- W>16 时条带自动缩格（保持格数、缩小格宽）。
