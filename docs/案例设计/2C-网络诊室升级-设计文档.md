# 案例 2-C《网络诊室 · 先预测》升级设计文档 v1.0

章节：第2章 深度学习基础 ｜ 大纲考点："解读训练/验证/测试三集指标" ｜ 课件依据：第二章 train/val 曲线与欠拟合/过拟合
状态：待实现 → 待评审 ｜ **在现有 L5 网络诊室骨架上加两处升级**（真实训练曲线、诊断牌、药架、早停标尺全部复用）

## 1. 学习目标（可检验行为）

1. 能从 train/val 曲线**反推训练配置**（容量 / 正则 / 学习率三个维度）——预测先于揭示；
2. 能说出三种**曲线签名**：训练↓验证↑ = 过拟合（背答案）；双高平 = 欠拟合（没学会）；高频抖动 = 训练不稳（步子太大/批量太小）；
3. 能说清三集划分：**测试集不画曲线**，模型定型后只用一次；验证集（反复看、调参）≠ 测试集（期末大考）。

## 2. 升级一：每份病历前加「预测配置」幕

流程变化（原来直接诊断，现在先预测）：

> 读曲线（**症状文字隐藏——它含答案**）→ 三选一预测配置 → 错选禁用+反例讲解 → 答对揭示机制+曲线签名 →「开始诊断」→ 原诊断牌/处方/复诊流程

三份病历的预测选项（干扰项按曲线签名混淆设计）：

| 病历 | 曲线特征（预测题干） | ✓ 正确配置 | ✗ 干扰 1 | ✗ 干扰 2 |
|---|---|---|---|---|
| #001 背答案的大网 | 训练→0.006、验证先降后升 | 64×64 双隐层、无正则、2500 轮 | 2 隐藏单元小网〔M-OF-03：训练线到 0.006 说明学得"太好"〕 | 学习率偏大〔M-OF-04：曲线平滑无抖动〕 |
| #002 学不会的小脑 | 双双卡 0.10 纹丝不动 | 2 个隐藏单元容量太小 | 64×64 大网无正则〔M-OF-03：那会先降很低再出"钩子"〕 | 学习率偏大〔M-OF-04：抖动≠睡着〕 |
| #003 喝醉的验证曲线 | 验证 0.11–0.21 剧烈抖动 | batch=4 且学习率偏大 | 2 隐藏单元小网〔M-OF-04：学不会≠学不稳〕 | 大网无正则训太久〔M-OF-02：过拟合是平滑钩子，不是振荡〕 |

- 错选：该按钮禁用划线 + 讲解**这种配置会长出什么样的曲线**（反例对照，练签名识别）→ 剩余选项重选；
- 答对：绿色机制揭示 + **曲线签名**一句话（直接为下一步诊断铺垫词汇）→「开始诊断 →」；
- 预测阶段隐藏诊断牌托盘 / 药架 / 处方单；预测面板占右侧栏；答对后才显示病历详情（症状文字）。

## 3. 升级二：毕业考核「测试集的曲线在哪？」

第三位病人痊愈后、通关结算前插入一问：

> 病历图上画了训练损失和验证损失两条曲线——**测试集的曲线在哪？**

- ✓ 测试集不画曲线：模型定型后只用一次、打个最终分；
- ✗ 应该还有第三条曲线，只是忘了画〔M-TR-01〕——测试集不参与逐轮训练，没有"随轮次变化的曲线"；
- ✗ 验证集就是测试集换个名字〔M-TR-02〕——验证集反复调参，测试集只用一次；混用=数据泄漏、成绩虚高。

揭示卡：训练/验证 = 日常作业/周测（反复看）；测试集 = 期末大考（只考一次，考前偷看试题 = 泄题）。→「领取毕业证书」→ 结算。

## 4. 判分与完成证据

- 记录 `{type:'predict_config', case, firstTry, correct, value, mId}` 与 `{type:'testset_q', firstTry, correct, value, mId}`；错选经 `wrong()` 计入 errs（进学情报告 mCounts）；
- 星级：`star2MaxErrors` 1 → **2**（新增预测幕，预测本来就是"学之前先猜"，留一次容错）；
- 完成证据：3 份病历诊断+处方全对；**预测环节首答正确率**（映射表 2-C 完成证据项）。

## 6. 工程要点

- `l5_clinic.js`：`loadCase` 拆两阶段（`phase='predict'` → `'diagnose'`）；预测面板（`#predPanel`）与药架/处方单（`#medPanel`/`#rxPanel`）互斥显隐；dx 牌、处方槽、服药按钮在 `beginDiagnose()` 才创建/绑定；
- 三集问在 `treat()` 成功链末尾（第 3 例痊愈后）`showTestQ()` 插入，通关结算从那里触发；
- 预测答错不重洗选项（剩余可选），答对后全部禁用——与 2-B/5-A 的"错→讲解→重问"节奏一致但保留按钮位置（反例讲解挂在错按钮下方）。
