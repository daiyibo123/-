## 6-1 压缩工坊 AE（l6a）
2D 双月牙数据（确定性生成）。线性 AE：2→1→2（编码 z=x·w₁+y·w₂，解码对称）。
**幕一 预测**：两张真实样本的潜码 z=+0.8 与 z=−0.6，取中点 z=0.1 解码，输出是？
✓ 两张的模糊重叠（鬼影）｜✗ 清晰的中间样本〔M-GE-01〕｜✗ 其中一张。
**幕二 揭示（真实计算）**：三张解码结果并排画出（真码 A / 真码 B / 插值码），插值点落在两月牙之间的空隙=鬼影。
**幕三 概念**：AE 为什么不能生成新样本？✓ 潜空间没有结构，采样点解码无意义〔✗ 参数太少→M-GE-01〕。
完成证据：预测+概念首答。

## 6-2 会做梦的潜空间 VAE（l6b）
同数据。VAE 潜空间：KL 把两簇压成连续正态。
**幕一 预测**：在 VAE 潜码连线上滑到中点，输出？✓ 平滑的中间过渡样本〔M-GE-02：以为还是鬼影/认为 VAE=AE 加深〕。
**幕二 滑杆交互（真实计算）**：α∈[0,1] 滑杆，输出点 = 双月牙两侧边界点的连续混合（数学上构造为两侧曲线的插值——展示"连续过渡"）；重参数化插图一问：z=μ+σ⊙ε 为什么？✓ 让随机性可反传〔M-GE-02〕。
**幕三 对比**：AE vs VAE 一表总结（重构/采样/清晰度）。
完成证据：预测+重参数化首答。

## 6-3 猫鼠大战 GAN（l6c）——页内真实交替训练
1D toy：真实数据 N(4,0.5)。G 是单参数生成器（输出 g）；D 是 sigmoid 判别器（参数 d）。
交替梯度下降（解析梯度，页内 setInterval 驱动，~200 轮）：D loss、G loss 实时曲线（真实数值）。
**幕一 预测**：训练中 D/G 损失形态？✓ 此消彼长振荡〔✗ 双双下降→M-GE-03〕。
**幕二 观战**：跑真实训练；学生点"生成 8 个样本"看 G 输出从乱到接近 4；一个"崩溃开关"把 G 学习率×10 → 样本坍缩到单点（真实模拟模式崩溃）。
**幕三 两问**：振荡≠失败；崩溃的表现=多样性消失。
完成证据：预测+两问首答+完成一次生成。

## 6-4 从噪声里捞图（l6d）——真实加噪/去噪
1D 信号（方波+细节，20 点）。正向：xₜ=√(1−β)·xₜ₋₁+√β·ε 逐步加噪（β=0.18，t=0..20，真实计算）。
**幕一 预测**：t=10 时信号长什么样？✓ 原形状依稀可辨的噪声版〔✗ 纯噪声（那是 t=20）→M-GE-04；更清晰〕。
**幕二 滑杆**：拖 t 看真实加噪序列；预测后打分（中点形状最像哪张，三选一）。
**幕三 反向打捞**：从 t=20 出发，每步减去"该步加的噪声的方向"（演示去噪轨迹动画，10 步回到近方波）；一问：为什么每步只去一点噪？✓ 小步逼近才稳定〔M-GE-04〕。
完成证据：预测+滑杆验证+末问。
