## 5-3 因果之幕（l5b）
短句 "the cat sat on the"（5 词），预测 "mat" 位置的自注意力。
**幕一 Mask 前预测**：完整注意力矩阵热图（5×5，行=query）。预测：把未来两格 score 设 −∞ 后，"on" 行的权重怎么变？
✓ 未来格归零、其余重新归一化（和仍 1）｜未来格变小但不为 0〔M-AT-06：Mask 是硬置零〕｜不变。
**幕二 盖幕交互**：拖动"幕布"滑杆从全部可见→因果可见，热图逐列熄灭+行重新归一化动画；数字表格实时更新。
**幕三 词序实验**：打乱词序按钮（cat↔sat 互换）——预测注意力输出会怎样？
✓ 一样（自注意力对顺序本身不敏感——词袋）→ 引出位置编码：加上位置后才能区分"猫坐"与"坐猫"。
概念一问：训练能并行的原因？✓ 每个位置各自带 Mask 独立计算，无需等前一步〔✗ 因为 GPU 快→M-AT-08〕。
完成证据：Mask 预测+词序预测+并行概念题首答。

## 5-4 王座之争（l5c）
同一长句（30 词，首尾远距离依赖："The key ... in the kitchen"），两种机制赛跑条形动画：
RNN：隐状态一站站传递，信号条逐段衰减（0.97ⁿ）；注意力：query 与远处 key 一步直连（信号条满格）。
**幕一 预测**：30 词的句尾要"用上"句首信息，谁的信号到达得更完整？✓ 注意力一步直连｜RNN（衰减少）｜一样。
**幕二 赛跑动画**：两条泳道动画演示；结果条：注意力 100% vs RNN 0.97²⁹≈40%。
**幕三 三轴三问**（预测-验证）：
1. 长距离依赖：✓ 注意力 O(1) 直连 vs RNN O(n) 传递；
2. 训练并行：✓ Transformer 全位置并行 vs RNN 必须逐步；
3. 代价：✓ 注意力 O(n²)，长序列算力显存吃紧——短序列低算力 RNN 仍有一席〔✗ Transformer 全面更好→M-AT-08〕。
完成证据：赛跑观看 + 三问首答。
