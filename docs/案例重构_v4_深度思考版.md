# 案例系统深度重构 v4 —— 从"表面计算"到"深度思考"

> 核心转变：删掉浮于表面的数值计算题，换成让计算机专业学生**真正动脑**的思考题和论述题。
> 新增两种案例类型：**思考题**（倒计时+快速递进）和**论述题**（自由写作+AI 判卷）。

## 设计原则

1. **不考算术，考洞察**——所有"计算 X = ?"类问题替换为"为什么 X 是这样的"
2. **小步递进**——每题只比上一题多想一步，30 秒~2 分钟可完成
3. **计算机专业深度**——涉及复杂度分析、设计权衡、底层原理，不是科普
4. **两种新类型**：
   - **思考题**：倒计时 60-120 秒，选择题但选项需要推理才能区分
   - **论述题**：不限时，自由文本，调大模型 AI 判卷

## 各章重新设计的案例

| 2-2 | 思考 | 将所有权重初始化为 0，训练时会发生什么？为什么？（提示：对称性） | 60s | 初始化+对称破缺 |

| 2-4 | 思考 | sigmoid 的梯度最大值只有 0.25。这对 10 层网络的反向传播意味着什么？ | 90s | 梯度消失的本质 |
| 2-5 | 思考 | ReLU 在负半区梯度为 0。什么情况下会导致"神经元死亡"？这一定是坏事吗？ | 90s | 激活函数权衡 |
| 2-6 | 论述 | 用不超过 200 字向一个懂微积分但不懂深度学习的同学解释：为什么需要反向传播而不是直接对每个权重数值求导？ | 不限时 | 算法理解+表达 |
| 2-7 | 思考 | 你有一个 2-4-4-1 的 MLP（2 输入 4 隐 4 隐 1 输出）。参数量是多少？如果把 4 个隐层神经元换成 100 个，参数量增长是线性还是超线性？为什么？ | 120s | 参数量本质 |
| 2-8 | 思考 | mini-batch size = 1（SGD）和 size = 全数据（GD）的梯度估计方差有什么区别？哪个方向的噪声更大？ | 90s | 优化器本质 |
| 2-9 | 思考 | 动量法 v←βv−η∇L 中，β=0.9 vs β=0.99，哪个"记忆"更长？对收敛速度和越过局部极小的能力各有什么影响？ | 90s | 动量的物理直觉 |

### 第 3 章 卷积神经网络

| 编号 | 类型 | 题目 | 倒计时 | 考察点 |
|---|---|---|---|---|
| 3-1 | 思考 | 全连接层处理 224×224×3 图片，第一层 1000 个神经元需要多少参数？卷积层 3×3×3 用 64 个核呢？这个差距的本质原因是什么？ | 90s | 权值共享的深层原因 |
| 3-2 | 思考 | 权值共享假设"图像的一个局部模式在任意位置都适用"。举一个这个假设失败的场景（提示：考虑位置信息重要的情况） | 60s | 归纳偏置的局限 |
| 3-3 | 思考 | 两个 3×3 卷积堆叠 vs 一个 5×5 卷积：感受野相同，但参数量分别是多少？非线性变换次数呢？ | 90s | 小核优势 |
| 3-4 | 思考 | 为什么 ResNet 的残差连接 F(x)+x 能解决梯度消失？从反向传播的角度解释（提示：∂(F(x)+x)/∂x 至少为 1） | 120s | 残差的数学本质 |
| 3-5 | 思考 | 池化层没有可学习参数，为什么还要放在网络里？如果去掉池化全部用 stride=2 卷积替代，有什么利弊？ | 90s | 池化的设计权衡 |
| 3-6 | 思考 | 在推理阶段，BatchNorm 使用训练时的移动平均而不是当前 batch 的统计量。为什么？如果用当前 batch 的会怎样？ | 90s | BN 的推理行为 |
| 3-7 | 论述 | 你在设计一个分类医学 CT 图像的系统。数据集只有 500 张标注图片。你会选择从头训练还是用 ImageNet 预训练模型做迁移学习？如果是迁移学习，你会冻结哪些层、微调哪些层？为什么？ | 不限时 | 迁移学习+实践设计 |
| 3-8 | 思考 | 数据增强（随机翻转/裁剪）为什么能减少过拟合？它的本质是在做什么？（提示：从数据分布的角度） | 90s | 数据增强原理 |

### 第 4 章 序列模型

| 编号 | 类型 | 题目 | 倒计 | 考察点 |
|---|---|---|---|---|
| 4-1 | 思考 | RNN 在时间维度上共享权重，CNN 在空间维度上共享权重。这两者"共享"的东西有什么本质区别？ | 90s | 权值共享的维度 |
| 4-2 | 思考 | BPTT 中梯度是连乘的。如果每步的 Jacobian 谱半径 < 1，传 50 步后梯度大约衰减到多少？这对学习"句首主语→句尾动词"的依赖意味着什么？ | 120s | 梯度消失定量 |
| 4-3 | 思考 | LSTM 的细胞状态 C 的更新是加法：C_t = f·C_{t-1} + i·c̃。为什么加法更新能缓解梯度消失？（对比 RNN 的乘法：h_t = tanh(W·h_{t-1}+...)） | 120s | LSTM 的数学核心 |
| 4-4 | 思考 | GRU 把 LSTM 的三门减为两门（更新门+重置门）。它丢掉了什么？在什么场景下 LSTM 仍然比 GRU 更优？ | 90s | GRU vs LSTM |
| 4-5 | 思考 | Teacher Forcing 在训练时用真实词做输入。生成时没有真实词。这个 gap 叫什么？它怎么影响生成长文本的质量？ | 90s | 暴露偏差 |
| 4-6 | 论述 | 你在做一个机器翻译系统，源语言平均句长 30 词，目标语言平均 50 词。你会选择 LSTM 还是 Transformer？从计算复杂度、长距离依赖捕获、训练并行性三个角度分析。 | 不限时 | 架构选择分析 |

### 第 5 章 Transformer 与注意力

| 编号 | 类型 | 题目 | 倒计时 | 考察点 |
|---|---|---|---|---|
| 5-1 | 思考 | 自注意力的计算是 O(n²·d)，RNN 是 O(n·d²)。当 n >> d 时哪个更高效？当 d >> n 呢？这解释了为什么 NLP 用 Transformer 而 CV 曾长期用 CNN？ | 120s | 复杂度分析 |
| 5-2 | 思考 | 注意力公式 softmax(QK^T/√d)·V 中，如果不除 √d，当 d=512 时 score 的标准差大约是多少？这对 softmax 的输出分布有什么影响？ | 90s | √d 的统计学原因 |
| 5-3 | 思考 | 8 个头各用 d/8=64 维 vs 1 个头用 d=512 维。总参数量相同。多头多出了什么能力？ | 90s | 多头注意力本质 |
| 5-4 | 思考 | 位置编码是"加"到词嵌入上的，不是"拼接"。如果拼接 (维度从 d 变 2d)，计算量会怎么变？加法为什么也能编码位置？ | 90s | 位置编码设计 |
| 5-5 | 思考 | 因果 Mask 把未来位置的 score 设为 −∞。训练时所有位置并行计算（各自带 Mask），生成时逐词自回归。这两种模式在计算效率上的差异是多少？ | 90s | 并行训练 vs 串行生成 |
| 5-6 | 思考 | 自注意力没有归纳偏置（不像 CNN 有局部性、RNN 有时序性）。为什么在小数据集上 Transformer 反而不如 CNN/RNN，但在大数据集上更强？ | 120s | 归纳偏置与数据规模 |
| 5-7 | 论述 | 解释为什么 BERT（双向注意力+Masked LM）和 GPT（因果注意力+自回归）在预训练策略上不同，导致它们各自适合什么下游任务？如果你要做一个情感分析模型，选哪个？ | 不限时 | 预训练范式 |

## 基础设施改造

### 1. 思考题引擎
- 倒计时显示（60/90/120 秒，按题设置）
- 到时自动揭示答案
- 选择题格式但选项需推理区分
- 小步递进：每题只比上一题多想一步

### 2. 论述题引擎
- 自由文本输入（textarea）
- 调用大模型 API 判卷
- AI 给出分数 + 逐条反馈
- 无倒计时
- 判分标准存储在知识库中

### 3. AI 判卷流程
```
学生提交 → 构造 prompt（题目+参考答案要点+学生答案）→ 调 LLM API → 解析 JSON 结果 → 展示分数+反馈
离线降级：关键词匹配 → 给出提示但无法精确判分
```
